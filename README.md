A program that writes one line — the excuse a dog gives after being caught eating the homework — to `/output/entry.txt`: `It was due today, so I turned it in early. Inside me.` Built by an AI agent for make.fun's "The Dog Ate My Homework: Funniest Excuse" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (53 characters, UTF-8, one line).
